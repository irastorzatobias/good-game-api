GOOD GAME API
=============

Poner esta carpeta en el servidor del local (por ejemplo C:\GoodGameAPI). No hace falta instalar nada mas.

1. Doble clic en good-game-api.exe
   La primera vez pide elegir la carpeta del sistema (Sistema_Local, la que tiene clientes.dbf).
   La recuerda en config.json. Mientras la ventana este abierta, la API funciona.
   Si Windows pregunta por el firewall, permitir el acceso.

2. (Opcional) Para que corra siempre, aunque nadie inicie sesion:
   cerrar la ventana del paso 1 y hacer doble clic en "Iniciar con Windows.bat".
   Para sacarlo: "Quitar inicio automatico.bat".
   Ojo: como servicio no ve las unidades de red mapeadas (Z:\...). Si el sistema esta en otra
   PC, en config.json usar la ruta de red completa (\\SERVIDOR\Sistema_Local).

Claves de los clientes (la app pide DNI y clave), desde una consola en esta carpeta:
   good-game-api.exe clave 33456789 1234

Promo, premios, avisos y regla de puntos: editar contenido.json (se toma solo, sin reiniciar).

La API nunca escribe en el sistema. Lo que pasa en la app (compras, canjes, mensajes, respuestas a
presupuestos, cambios de contacto) se guarda en la carpeta "datos". Hacer copia de esa carpeta.

Para actualizar: doble clic en "Actualizar.bat". Baja la ultima version publicada, reemplaza los
programas y vuelve a arrancar la API. No toca config.json, contenido.json ni la carpeta datos.

Panel del local (cuentas de los clientes): crear el usuario una vez, en una consola dentro de esta carpeta:
  good-game-api.exe admin <usuario> <clave>
y despues entrar a la app en /admin.

Copias de seguridad: la API guarda una copia por dia de datos\app.db (cuentas y claves de los clientes)
en la carpeta "Backup App", al lado de la carpeta del sistema, y conserva las ultimas 14.
Para hacer una en el momento: good-game-api.exe backup
Para recuperar: parar la API, copiar la copia elegida sobre datos\app.db (con ese nombre) y volver a arrancarla.

Estado: con la API instalada como servicio, abrir good-game-api.exe (o el acceso directo "Estado Good Game API"
del escritorio) muestra si la API, el tunel, el acceso desde internet y las copias andan. R reinicia todo.

Indicador: al lado del reloj, un punto verde (todo anda), amarillo (no se llega desde internet) o rojo
(la API no responde). Doble clic: detalle. Clic derecho: reiniciar. Lo instala "Iniciar con Windows" y arranca
al iniciar sesion. Si no se ve, puede estar en la flecha ^ de la bandeja: arrastrarlo al lado del reloj.
